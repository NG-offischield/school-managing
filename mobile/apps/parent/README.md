# School Managing — application parent

- **Compte :** créer mon compte (validé par l'établissement), connexion, compte en attente.
- **Rattachement :** demande (matricule, date de naissance, pièce d'identité vérifiée à l'école), code de
  parrainage d'un second parent.
- **Suivi de l'enfant :**
  - accueil avec sélecteur d'enfant ;
  - présences (bilan, convocations, passages au portail, historique) ;
  - planning (jour ou semaine, changements) ;
  - scolarité et paiements, selon les droits accordés ;
  - bulletins officiels (PDF) et vérification d'un document.
- **Échanges :** notifications, messages (administration, enseignants de l'enfant), réclamations ;
  profil.

Voir `mobile/README.md` et l'ADR 0026.
